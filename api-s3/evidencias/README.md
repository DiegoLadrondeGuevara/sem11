# Evidencias pendientes del despliegue

Esta carpeta se completará después de ejecutar el laboratorio en CloudShell.
No se incluyen capturas ni resultados simulados.

Para cada stage (`dev`, `test`, `prod`), guardar:

1. Salida de `serverless deploy --stage STAGE` y `serverless info --stage STAGE`.
2. Captura de Linux con las cinco solicitudes `curl` y sus códigos HTTP.
3. Capturas de Postman con las cinco solicitudes y respuestas.
4. Capturas de S3 que muestren bucket, directorio y archivo; comprobar tamaño y tipo del archivo.

Luego se reunirán las capturas reales en un único Word o PDF.
